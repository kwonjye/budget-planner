# Budget Planner (나만의 가계부)

> 한양사이버대학교 졸업 과제&nbsp;&nbsp;|&nbsp;&nbsp;2024.09 - 2024.10&nbsp;&nbsp;|&nbsp;&nbsp;🏆 우수 작품 선정  
> 개인 프로젝트 (기획/설계/개발 단독 수행)

## 📌 소개
Spring Boot 기반 개인 맞춤형 가계부 웹 애플리케이션

## 🛠 Tech Stack
Spring Boot, Thymeleaf, MySQL, Redis, AWS EC2/RDS

## ✨ 주요 구현
- 자산/예산/지출 관리 기능 구현
- BCrypt + Session 기반 인증 및 Interceptor 적용
- Redis 기반 이메일 인증 시스템
- Database Trigger로 회원가입 시 기본 카테고리 자동 생성
- Chart.js를 활용한 지출 분석 시각화
- AWS 환경에서 배포 구성 경험
